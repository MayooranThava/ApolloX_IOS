Void Runner Support

Portrait arcade shooter for iPhone · com.mayooran.ApolloX

Quick help

  • Sound / haptics: Title → Settings
  • How to play: Settings → How to Play (or the title-screen How to Play button)
  • Ranks: Sign in to Game Center (iOS Settings → Game Center), then open Ranks in the game
  • Ships and weapons: Earn credits from runs, then open Store (Hangar)
  • Pause: Tap pause during a run; the game stays paused if you leave the app

Game Center “*MISSING TITLE*” or Pre-release

In App Store Connect → Features → Game Center → your leaderboard, add an English localization named High Score, then include the leaderboard when you submit the app version. Pre-release clears after that version is live or approved for TestFlight with the component attached.

Contact

Email the developer address shown on the App Store listing for Void Runner, or open an issue on the project repository if you have access.
