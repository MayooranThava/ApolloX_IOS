Void Runner Support

Portrait arcade shooter for iPhone · com.mayooran.ApolloX

Quick help

  • Sound / haptics: Title → Settings
  • How to play: Settings → How to Play
  • Ranks: Sign in to Game Center (Settings → Game Center), then open Ranks in the game
  • Ships: Earn credits from runs, then open Store

Game Center “*MISSING TITLE*” or Pre-release

In App Store Connect → Features → Game Center → your leaderboard, add an English localization named High Score, then include the leaderboard when you submit the app version. Pre-release clears after that version is live or approved for TestFlight with the component attached.
