# ApolloX browser preview

Interactive phone-frame preview that loads the **current Asset Catalog sprites** from `ApolloX/Assets.xcassets` (copied into `demo/assets/`).

```bash
cd demo
python3 -m http.server 8765
# open http://127.0.0.1:8765/apollox-demo.html
# or autodemo: http://127.0.0.1:8765/apollox-demo.html?autodemo=1
